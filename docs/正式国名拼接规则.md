# 正式国名拼接规则（国名 + 政体）

## 目标

报纸/杂志抬头原本为：

    国名：大清｜都城：北京｜政体：专制帝国｜年份：1836

改为把政体并入国名，形成正式国名，并去掉独立的政体字段：

    国名：大清帝国｜都城：北京｜年份：1836
    国名：法兰西第三共和国｜都城：巴黎｜年份：1861

实现集中在 `journal.py` 的 `full_country_name(country, govt)`，报纸（`journal.py`）、
杂志（`magazine.py`）、存档数据管道（`journal_save.py` 的 `data["player_full"]`）统一复用。

## 规则总览

1. **豁免：国名已以「国」结尾** —— 视为已完成命名，直接原样使用，不做拼接。
   - 美利坚合众国、法兰西共和国、教宗国、卡尔萨帝国、中美洲联邦共和国（若游戏如此命名）
2. **只取政体名的「国体后缀」** —— 剥掉「专制/立宪/封建/社会/民主/议会/总统/委员会」等
   通用修饰语，只留后缀拼到国名后：
   - 大清 + 专制帝国 → 大清帝国
   - 普鲁士 + 立宪君主国 → 普鲁士王国
   - 巴西 + 立宪帝国 → 巴西帝国
   - 意大利 + 民主共和国 → 意大利共和国
3. **带序号的共和国整段保留** —— 是正式国名的一部分：
   - 法兰西 + 第三共和国 → 法兰西第三共和国
   - 法兰西 + 第二共和国 → 法兰西第二共和国
4. **国名已含该后缀不重复拼接**：
   - 德川幕府 + 幕府 → 德川幕府
5. **非国名后缀的政体不拼接**，保留原国名：
   - 海地 + 军事独裁政府 → 海地
   - 教宗国 + 英王陛下政府 → 教宗国（同时命中豁免）

## 已知取舍

- 「君主国 → 王国」「凯撒国/沙皇国 → 帝国」是按中文正式国名惯例的规范化：
  历史上写作「普鲁士王国」「奥地利帝国」而非「普鲁士君主国」「奥地利凯撒国」。
- 军事独裁政府、英王陛下政府等**不是国名后缀**，强行拼接会产生「海地军事独裁政府」这类
  不像国名的结果，因此保留原国名、不拼接；政体信息仍存在于提示词与正文语境中。
- 不做「国家级特殊改名」（如把中美洲强行写成「中美洲联邦共和国」），以跟随游戏当前政体为准，
  避免改名与存档状态脱节。
